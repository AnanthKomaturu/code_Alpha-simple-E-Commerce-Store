# 🛒 Simple E-Commerce Store

A simple **frontend e-commerce website** where users can view products, add products to the cart, and manage their shopping items.

## ✨ Features

* 🛍️ View products
* 🔎 Search products
* 🛒 Add products to cart
* ➕ Increase product quantity
* ➖ Decrease product quantity
* 🗑️ Remove products from cart
* 💰 Calculate total price
* 📱 Responsive design

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Structure


Simple-Ecommerce-Store/
│
├── index.html
├── style.css
└── script.js

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start shopping!
